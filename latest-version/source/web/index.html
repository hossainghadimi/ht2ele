۲. تنظیمات خروجی

قبل از تبدیل، ورودی را اصلاح کنید

تب «پیش‌نمایش و اصلاح ورودی» بدون تبدیل باز می‌شود. روی المان کلیک کنید، نوع ویجت و استایل را تعیین کنید، سپس تبدیل را بزنید. در ویرایش خروجی نیز «تغییر نوع ویجت» و بازگشت تغییر در دسترس است.

خروجی نرم‌افزار چیست؟

برای هر فایل HTML سه چیز ساخته می‌شود:

name.json — قالب رسمی المنتور (version 0.4) برای وارد کردن از کتابخانه قالب‌ها.
name.css — تمام CSSهای داخل صفحه، فایل‌های لینک‌شده، و استایل اینلاین باقی‌مانده. جدا از JSON.
name.clipboard.json — فرمت Paste داخل بوم المنتور (راست‌کلیک → Paste).

روش ۱ — وارد کردن قالب (پیشنهادی)

  1. در پیشخوان وردپرس بروید به قالب‌ها ← قالب‌های ذخیره‌شده (Templates → Saved Templates).
  2. دکمه وارد کردن قالب (Import Templates) را بزنید.
  3. فایل .json را انتخاب کنید.
  4. برگه یا نوشته را با المنتور باز کنید → افزودن قالب → قالب واردشده را درج کنید.

روش ۲ — چسباندن مستقیم در بوم

  1. دکمه «کپی برای Paste در المنتور» را بزنید.
  2. صفحه را با المنتور باز کنید، روی بوم راست‌کلیک کنید و Paste را بزنید.

فایل CSS را کجا بگذارم؟

طبق خواسته شما CSS داخل JSON قاطی نمی‌شود و فایل جدا است. یکی از این کارها را بکنید:

  1. ظاهر ← سفارشی‌سازی ← CSS اضافی و محتوای فایل CSS را پیست کنید.
  2. فایل CSS را در چایلد‌تم بگذارید و از قطعه PHP همراه خروجی (enqueue-*.php) استفاده کنید.
  3. اگر المنتور پرو دارید، می‌توانید CSS را در Site Settings → Custom CSS هم بگذارید.

کلاس‌های اصلی HTML روی کانتینر/ویجت‌ها در فیلد Advanced → CSS Classes حفظ می‌شوند تا همان فایل CSS روی طرح اعمال شود.

کدام حالت تبدیل را انتخاب کنم؟

ترکیبی: تیتر، متن، تصویر، دکمه، لیست و ویدیو می‌شوند ویجت بومی. فرم و جدول پیچیده داخل HTML می‌مانند؛ آیکن‌های شناسایی‌شده ویجت آیکن خالی می‌شوند.
ویجت‌های بومی: حداکثر ویرایش‌پذیری در المنتور. ممکن است جزئیات طرح کمی فرق کند.
ویجت HTML: کل بدنه صفحه داخل یک ویجت HTML است. با فایل CSS جدا، نزدیک‌ترین ظاهر به HTML اصلی را می‌دهد ولی ویرایش بلوکی سخت‌تر است.

تبدیل هوشمند تصویر طرح با Qwen-VL

تب «تصویر به طرح با Qwen» تصویر را با مدل بینایی و فایل mmproj تحلیل می‌کند و کانتینرها و ویجت‌های بومی قابل‌ویرایش می‌سازد. مدل متنی قبلی کافی نیست. لینک دو فایل لازم داخل همان تب است. ریسپانسیو، فونت و لینک‌ها نیاز به بازبینی دارند.

روش سادهٔ قدیمی تصویر — بدون مدل

اسکرین‌شات PNG/JPG یک سکشن را رها کنید. برنامه نوارهای افقی/عمودی را تشخیص می‌دهد، کانتینر ردیف یا ستون می‌سازد، رنگ یکدست را پس‌زمینه می‌کند و محتوای پیچیده را به‌صورت ویجت تصویر برش می‌دهد.

نکته‌ها

  • اگر صفحه به فایل CSS خارجی لینک شده، همان فایل CSS را هم همراه HTML در نرم‌افزار رها کنید.
  • تگ‌های <script> به‌صورت ویجت HTML در قالب می‌مانند.
  • تصاویر با URL موجود در HTML ذخیره می‌شوند. بعد از ایمپورت، بهتر است تصاویر را در رسانه وردپرس آپلود کنید.
  • سلکتورهایی مثل .hero > h1 ممکن است به‌خاطر پوشش HTML المنتور دقیق کار نکنند؛ در این صورت حالت «ویجت HTML» را امتحان کنید.
  • در تب پیش‌نمایش و ویرایش روی هر المان کلیک کنید. پنل تنظیمات (محتوا، استایل، پیشرفته) شبیه المنتور باز می‌شود و JSON همان لحظه به‌روز می‌گردد.
