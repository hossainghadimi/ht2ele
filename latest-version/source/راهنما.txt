HTML به المنتور
================

این برنامه برگه‌های HTML آماده‌شده را به فایل JSON المنتور تبدیل می‌کند
و CSS را در فایل جدا ذخیره می‌کند.

اجرا روی ویندوز
---------------
1) پایتون ۳ را نصب کنید (تیک Add to PATH را بزنید)
2) روی run.bat دابل‌کلیک کنید
3) مرورگر باز می‌شود

استفاده
-------
- فایل‌های HTML را بکشید و در کادر رها کنید
- فایل‌های CSS مرتبط را هم رها کنید
- دکمه «تبدیل به المنتور» را بزنید
- JSON و CSS را دانلود کنید

وارد کردن در وردپرس
-------------------
قالب‌ها → قالب‌های ذخیره‌شده → وارد کردن قالب → فایل JSON

CSS جدا:
ظاهر → سفارشی‌سازی → CSS اضافی
یا فایل CSS را در قالب enqueue کنید

حالت‌ها
-------
ترکیبی: بهترین تعادل بین ویرایش در المنتور و حفظ طرح
ویجت‌های بومی: همه چیز تا حد ممکن ویجت المنتور می‌شود
ویجت HTML: کل صفحه یکجا؛ نزدیک‌ترین ظاهر به HTML اصلی
