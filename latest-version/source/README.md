# HTML به المنتور

نرم‌افزار ویندوزی برای تبدیل **HTML یا تصویر طرح با Qwen-VL** به **قالب JSON المنتور** با **فایل CSS جداگانه**.

خروجی با ساختار رسمی المنتور نسخه **0.4** ساخته می‌شود و از مسیر **قالب‌ها → قالب‌های ذخیره‌شده → وارد کردن قالب** قابل ایمپورت است.

## بسته ویندوز (EXE)

فایل آماده:

`../versions/HTML2Elementor-Windows-v1.8.0.zip` (SHA-256 در `../versions/SHA256SUMS-v1.8.0.txt`)

برای Windows 10/11 نسخه ۶۴بیتی. داخل بسته `HTML2Elementor.exe` است — بدون نصب پایتون. ZIP را کامل استخراج و EXE را اجرا کنید. پیش از تأیید هشدار فایل بدون امضا، منبع و هش بسته را بررسی کنید. وزن مدل و CUDA در ZIP سبک نیستند.

## نسخه جاری ۱.۸.۰ — دو مرحله با چت‌باکس AI + مدل‌های محلی + GPU/CPU همزمان

[راهنمای کامل نسخه ۱.۸.۰](docs/RELEASE-v1.8.0.md)

- **مرحلهٔ ۱ (تصویر → HTML):** تحلیل تصویر، سپس **HTML بازسازی‌شده + چت‌باکس AI** برای ویرایش بدون کد (پیش‌نمایش قبل از اعمال) و کادر ویرایش مستقیم؛ «تأیید نهایی» HTML را به مرحلهٔ ۲ می‌فرستد.
- **مرحلهٔ ۲ (HTML → المنتور):** بوم ورودی با **چت‌باکس AI** برای اصلاحات نهایی (Undo حفظ می‌شود)، سپس تبدیل به JSON/CSS المنتور.
- **مدل‌های محلی:** ثبت مسیر، **اسکن دیسک** (با تعداد لایهٔ واقعی هر GGUF) و **ایمپورت مستقیم** تا 8MB در «کارگاه AI»؛ پیشنهادهای مدل برای 8GB VRAM با لینک مخزن رسمی (Qwen3-VL-8B/4B + mmproj، Qwen3-4B متنی برای چت‌باکس).
- **GPU+CPU همزمان (hybrid):** لایه‌های مدل بین GPU و CPU تقسیم می‌شود؛ ngl خودکار از تعداد لایهٔ GGUF و VRAM تخمین می‌شود و قابل تنظیم است.
- خروجی چت‌باکس **هیچ‌وقت خودکار اعمال نمی‌شود**؛ پیش‌نمایش + دکمهٔ «اعمل» لازم است.

## نسخهٔ ۱.۷.۰ — تصویر به المان قابل‌ویرایش

[راهنمای کامل نصب مدل و محدودیت‌ها](docs/RELEASE-v1.7.0.md)

- تصویر طرح را در تب «تصویر → ویجت با Qwen» وارد کنید؛ مدل VL و فایل mmproj متناظر را ثبت کنید.
- پیشنهاد شروع برای VRAM هشت گیگابایتی: **Qwen3-VL-4B-Instruct Q4_K_M + mmproj Q8_0**، مجموع فایل‌ها حدود ۲٫۹۵ GB؛ مصرف RAM/VRAM بیشتر از صرفِ اندازهٔ فایل‌هاست و روی سخت‌افزار شما تست نشده.
- [مدل رسمی](https://huggingface.co/Qwen/Qwen3-VL-4B-Instruct-GGUF/resolve/main/Qwen3VL-4B-Instruct-Q4_K_M.gguf?download=true) · [فایل بینایی](https://huggingface.co/Qwen/Qwen3-VL-4B-Instruct-GGUF/resolve/main/mmproj-Qwen3VL-4B-Instruct-Q8_0.gguf?download=true)
- تحلیل تصویر → دادهٔ ساختاریافتهٔ اعتبارسنجی‌شده → کانتینر و ویجت‌های بومی، سپس ویرایش بصری و JSON/CSS. فقط نواحی عکس برش می‌خورند. خطای مدل مخفیانه با برش ساده جایگزین نمی‌شود.
- بازبینی کادرها/متن/نوع و بازسازی؛ لغو و توقف مدل؛ ZIP شامل عکس‌ها، طرح تشخیص و HTML بازسازی‌شده.
- چیدمان و OCR تخمینی‌اند؛ ریسپانسیو واقعی، فونت و لینک از تصویر قابل بازیابی قطعی نیستند. عکس‌های خروجی را در رسانهٔ وردپرس بارگذاری و URLها را جایگزین کنید.
- تست ساخت ویجت‌ها با fixture و تست واقعی مسیر بینایی با مدل کوچک SmolVLM انجام شده؛ **Qwen3-VL-4B، Windows/RTX و ایمپورت زندهٔ وردپرس هنوز تست نشده‌اند**.

## اجرا از روی سورس

1. [Python 3](https://www.python.org/downloads/) را نصب کنید و گزینه **Add python.exe to PATH** را فعال بگذارید.
2. پوشه `html2elementor` را هر جا خواستید کپی کنید.
3. روی **`run.bat`** دابل‌کلیک کنید.
4. مرورگر با آدرس `http://127.0.0.1:7788/` باز می‌شود. همان پنجره سیاه را نبندید.

بازکردن مستقیم `web/index.html` فقط امکانات مرورگری را می‌دهد؛ مدل بینایی و کارگاه AI به اجرای سرویس محلی نیاز دارند. برای اجرای AI از سورس، وابستگی‌های `requirements-ai.txt` و موتور مناسب سیستم‌عامل نیز لازم‌اند.

## کار با برنامه

1. فایل‌های `.html` برگه‌ها را رها کنید.
2. اگر صفحه به `.css` لینک شده، همان فایل‌های CSS را هم رها کنید.
3. حالت تبدیل را انتخاب کنید:
   - **ترکیبی (پیشنهادی):** تیتر، متن، تصویر، دکمه، لیست و ویدیو → ویجت بومی؛ فرم/جدول/SVG/منوی پیچیده → ویجت HTML
   - **ویجت‌های بومی:** حداکثر قابلیت ویرایش داخل المنتور
   - **ویجت HTML:** کل صفحه داخل یک ویجت HTML (نزدیک‌ترین ظاهر به طرح اصلی)
4. **تبدیل به المنتور** را بزنید.
5. برای هر برگه دانلود کنید:
   - `name.json` — قالب المنتور
   - `name.css` — استایل جدا
   - ZIP کامل (JSON + CSS + clipboard + قطعه PHP)

## وارد کردن در وردپرس / المنتور

**قالب:** پیشخوان → قالب‌ها → قالب‌های ذخیره‌شده → Import Templates → انتخاب JSON.

**چسباندن سریع:** دکمه «کپی برای Paste در المنتور» → در بوم المنتور راست‌کلیک → Paste.

**CSS:** چون طبق درخواست شما جدا ساخته می‌شود:

- ظاهر → سفارشی‌سازی → CSS اضافی، یا
- فایل CSS را در چایلد‌تم بگذارید و از `enqueue-*.php` استفاده کنید.

کلاس‌های HTML روی ویجت‌ها در **Advanced → CSS Classes** حفظ می‌شوند.

## یادداشت تاریخی نسخه ۱.۳.۰

- بوم پیش‌نمایش اسکرول عمودی مستقل و قابل استفاده با ماوس، لمس و صفحه‌کلید دارد.
- ساختار اصلی فرزندان حفظ می‌شود؛ ستون‌های هم‌اندازه مصنوعی حذف شدند.
- اندازه‌گیری CSS در مرورگر ایزوله، با رعایت specificity، `!important`، ارث‌بری و واحدهای نسبی.
- نمونه‌برداری دسکتاپ ۱۲۰۰، تبلت ۷۶۸ و موبایل ۳۷۵ پیکسل؛ کنترل‌های پشتیبانی‌شده با پسوندهای المنتور ذخیره می‌شوند.
- کنترل‌های Grid واقعی (`grid_columns_grid`، `grid_rows_grid`، `grid_gaps`) و ستون‌های نامساوی.
- آیکن‌های Font Awesome 5 در پیش‌نمایش آفلاین بسته‌بندی شده‌اند (مجوز داخل vendor).
- شناسایی بیشتر ویجت‌ها؛ جدول دامنه پشتیبانی در `docs/RELEASE-v1.3.0.md`.
- کلیک روی المان → محتوا / استایل / پیشرفته؛ تغییرات در JSON، فایل خروجی و بوم همگام می‌شوند.
- آیتم‌های تب/آکاردئون، شبکه‌های اجتماعی و گالری از طریق آرایه JSON در پنل قابل ویرایش‌اند.

### نکات مهم

JSON و CSS خروجی را **با هم** در سایت استفاده کنید. برای فایل‌هایی که به CSS یا تصاویر/فونت‌های بیرونی وابسته‌اند، دارایی‌های اصلی باید در دسترس باشند. این ابزار موتور واقعی وردپرس/المنتور نیست و تضمین پیکسل‌به‌پیکسل برای هر HTML ندارد. اجزای ناشناخته یا Pro بدون معادل مطمئن در HTML حفظ می‌شوند. نقشه، SoundCloud، ویدیوهای آنلاین و شورت‌کدهای وردپرس ممکن است در پیش‌نمایش محلی فقط نمای ساده یا جایگزین داشته باشند.

ورودی تصویر همچنان به نواحی تصویری داخل کانتینر تقسیم می‌شود؛ متن/ویجت‌های بومی از اسکرین‌شات با OCR بازسازی نمی‌شوند.

اسکریپت‌های ورودی در ویجت HTML خروجی می‌مانند ولی برای ایمنی در پیش‌نمایش زنده اجرا نمی‌شوند. اسکریپت‌های ناشناس را پیش از وارد کردن در سایت بررسی کنید.

### آرشیو نسخه‌ها

پوشه `versions` نسخه‌های ZIP موجود را نگه می‌دارد؛ بسته‌های حذف‌شده بازسازی نمی‌شوند. فایل `manifest.json` نام، اندازه و SHA-256 موجودها را ثبت می‌کند. `/download/windows.zip` آخرین بسته و `/versions.html` فهرست بسته‌های موجود را ارائه می‌دهند.

## یادداشت تاریخی ۱.۵.۰

[یادداشت انتشار و محدودیت‌ها](docs/RELEASE-v1.5.0.md)

- تب **پیش‌نمایش و اصلاح ورودی** قبل از تبدیل: انتخاب المان، تعیین نوع ویجت، متن/لینک، CSS برای همه دستگاه‌ها یا موبایل/تبلت و بازگشت تغییر.
- در خروجی، **تغییر نوع ویجت** و **بازگشت تغییر نوع** اضافه شده است: متن↔دکمه، HTML→آیکن خالی و مقصدهای محتوایی دیگر.
- CSS به ترتیب واقعی لینک/استایل خوانده می‌شود؛ specificity، !important و box-sizing در اندازه‌گیری لحاظ می‌شوند.
- ورودی و خروجی هر دو viewport مرورگر مستقل دارند. خروجی دسکتاپ ۱۲۰۰، تبلت ۷۶۸ و موبایل ۳۷۵ پیکسل است؛ اسکرول صفحه داخل iframe انجام می‌شود.
- آیکن‌های SVG کوچک و آیکن‌های داخل متن/منو به HTML والد تبدیل نمی‌شوند؛ انتخاب دستی نوع برای اصلاح تشخیص نیز در دسترس است.
- تغییرات ورودی روی نسخه کاری مرورگر هستند، نه فایل اصلی دیسک. با ویرایش مجدد ورودی، خروجی قبلی پاک می‌شود تا دوباره تبدیل کنید.

کتابخانه‌های آفلاین همراه: Font Awesome 5، specificity و وابستگی CSS Tree/MDN Data. مجوزها در `web/vendor` قرار دارند.


## یادداشت تاریخی نسخه ۱.۶.۰ — آفلاین سبک با کارگاه AI

[راهنمای کامل نسخه ۱.۶](docs/RELEASE-v1.6.0.md)

- Python قابل‌حمل، Pillow و micrograd و موتور llama.cpp CPU همراه ZIP؛ بدون نصب pip یا CUDA برای استفادهٔ پایه.

- بانک ویژگی‌های برچسب‌خورده، آموزش دسته‌بند کوچک، پیشنهاد نوع و تأیید دستی روی ورودی. این مرحله فاین‌تیون Qwen یا بینایی عمیق ازپیش‌آموزش‌دیده نیست.
- حذف و بازگشت، درگ ترتیب المان‌های هم‌سطح و دستگیرهٔ اندازه، مخصوص breakpoint انتخاب‌شده؛ ورودی و خروجی هر دو پشتیبانی می‌شوند.
- ثبت ظاهر در سه عرض استاندارد پیش از تغییر نوع و نگاشت خصوصیات مشترک با تنظیمات بومی و CSS همراه.
- تمام ZIPهای قدیمی حفظ شده‌اند؛ آرشیو از این نسخه فهرست دانلودهاست، نه یک ZIP تجمیعی تکراری جدید.

اجرای واقعی GGUF با Qwen2.5-0.5B روی Linux CPU آزموده شد. اجرای Windows/RTX و ایمپورت WordPress در محیط حاضر آزموده نشده‌اند. حتماً JSON و CSS را با هم استفاده کنید.
