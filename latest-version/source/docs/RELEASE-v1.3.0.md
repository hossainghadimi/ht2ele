# HTML2Elementor — نسخه ۱.۳.۰

## تغییرات

### پیش‌نمایش و ویرایش
- بوم با ارتفاع محتوای واقعی و ناحیه اسکرول مستقل؛ بدون بریده‌شدن انتهای صفحه.
- کلیک روی المان، باز شدن پنل محتوا/استایل/پیشرفته و همگام‌سازی JSON.
- نمایش واقعی Font Awesome 5 Solid / Regular / Brands از فونت‌های همراه بسته؛ بدون نیاز به CDN.
- نمایش آیکن SVG داده‌شده و حفظ SVGهای عمومی داخل HTML.
- نمایش بیشتر ویجت‌های Core، باز/بسته‌شدن پنل‌های آکاردئون و تب در بوم.
- آرایه‌های محتوای گالری/تب/شبکه اجتماعی قابل ویرایش‌اند و JSON نامعتبر ثبت نمی‌شود.

### تبدیل و چیدمان
- فرزندان مستقیم Flex/Grid دیگر داخل ستون‌های ساختگی هم‌اندازه قرار نمی‌گیرند.
- جهت‌های row، column، row-reverse و column-reverse از ورودی خوانده می‌شوند؛ RTL/LTR صریح ورودی بر گزینه پیش‌فرض مقدم است.
- CSS با مرورگر در iframe بدون اجرای اسکریپت و بدون دریافت دارایی خارجی اندازه‌گیری می‌شود. ارث‌بری، اولویت سلکتورها، !important و rem/em در مقادیر محاسبه‌شده لحاظ می‌شوند.
- اندازه‌گیری در سه عرض ۱۲۰۰، ۷۶۸ و ۳۷۵ پیکسل؛ تنظیمات واکنش‌گرای قابل‌نگاشت با پسوندهای _tablet و _mobile نوشته می‌شوند.
- فونت، padding/margin هر ضلع، gap ردیف/ستون و اندازه آیکن نگاشت می‌شوند.
- Grid مساوی یا سفارشی با کلیدهای Core: grid_columns_grid، grid_rows_grid و grid_gaps. مسیر کنترل با سورس عمومی Core بررسی شده است.
- استایل‌هایی که کنترل معادل ندارند در CSS همراه خروجی حفظ می‌شوند.
- پدینگ دکمه از فاصله خارجی ویجت تفکیک شده است؛ فهرست معمولی دیگر بی‌دلیل آیکن تیک نمی‌گیرد.

## دامنه شناسایی ویجت‌ها

شناسایی بر پایه تگ‌ها، کلاس‌ها، role، data attribute و ساختار داخلی انجام می‌شود؛ ادعای تشخیص قطعی **تمام ویجت‌های همه افزونه‌ها** نیست.

| نوع | وضعیت / الگوی شناسایی |
|---|---|
| heading، text-editor، image، button | تگ‌های معمول HTML و کلاس‌های دکمه |
| divider، spacer | hr، بلوک خالی دارای ارتفاع |
| icon | کلاس‌های شناخته‌شده Font Awesome یا SVG با نشانه icon |
| icon-list | لیستی که هر آیتم آن آیکن مشخص دارد؛ لیست معمولی با HTML حفظ می‌شود |
| icon-box، image-box | جعبه ساده با کلاس صریح، عنوان، توضیح و رسانه؛ کارت پیچیده کانتینر می‌ماند |
| social-icons | social-icons / social-links / socials و لینک‌های دارای آیکن |
| image-gallery، image-carousel | مجموعه تصویر با نشانه گالری/اسلایدر؛ همراه متن پیچیده به ساختار اصلی برمی‌گردد |
| accordion، toggle، tabs | details/summary یا عنوان و پنل مرتبط با aria-controls/data-bs-target |
| counter | counter یا data-counter با عدد قابل تشخیص |
| progress | progress یا role=progressbar و الگوی progress-bar |
| alert | role=alert یا alert |
| testimonial | testimonial با متن، نام و مشخصات قابل تشخیص |
| star-rating | rating / star-rating همراه data-rating |
| google_maps | iframe نقشه دارای q/query؛ لینک pb مبهم عیناً در HTML حفظ می‌شود |
| video | YouTube/Vimeo و video میزبانی‌شده ساده؛ ویدیو با track یا sourceهای متعدد در HTML |
| audio | iframe SoundCloud؛ audio معمولی در HTML برای حفظ منبع |
| menu-anchor | لنگر خالی دارای id یا data-h2e-widget صریح |
| shortcode، read-more | فقط با data-h2e-widget صریح |
| فرم، جدول، منوی پیچیده، SVG عمومی، کد سفارشی | ویجت HTML؛ هیچ وابستگی اجباری به Elementor Pro اضافه نمی‌شود |

اجزای وردپرسی وابسته به سرور مانند sidebar، WooCommerce، محتوای پویا، فرم Pro، popup و ویجت‌های افزونه‌های شخص ثالث از HTML ساده به ویجت عملیاتی سروری بازسازی نمی‌شوند. HTML موجود حفظ می‌شود؛ بازسازی منطق سمت سرور نیازمند تنظیم در وردپرس است.

## محدودیت‌های مهم
- این بوم شبیه‌ساز محلی است، نه اجرای واقعی WordPress/Elementor. تطابق پیکسل‌به‌پیکسل برای HTML دلخواه تضمین نمی‌شود.
- قالب JSON و CSS همراه آن باید با هم استفاده شوند. فونت/تصویر سفارشی باید در سایت مقصد در دسترس باشد.
- فونت سفارشی در اندازه‌گیری ایزوله دانلود نمی‌شود؛ اندازه فونت خوانده می‌شود ولی ابعاد دقیق متن می‌تواند با فونت مقصد متفاوت باشد.
- شکست‌های واکنش‌گرای سفارشی و کنترل‌هایی که معادل native ندارند همچنان به CSS و بررسی در سایت مقصد نیاز دارند. خروجی مدرن Container توصیه می‌شود؛ حالت Section قدیمی نگاشت چیدمان محدودتری دارد.
- گالری/کاروسل در بوم نمای تصویری ساده دارند؛ نقشه، SoundCloud و شورت‌کد ممکن است جایگزین متنی داشته باشند. رفتار کامل به سرویس آنلاین یا سایت مقصد نیاز دارد.
- اسکریپت در JSON و HTML خروجی باقی می‌ماند، اما در بوم زنده اجرا نمی‌شود. اجرای اسکریپت سفارشی در سایت مقصد تضمین نشده است.
- ورودی تصویر به کانتینر و قطعات تصویری تبدیل می‌شود؛ این نسخه OCR یا استخراج متن و ویجت بومی از پیکسل‌ها ندارد.
- SVG داده‌ای ممکن است برای استفاده در سایت نیازمند بارگذاری مجاز SVG در کتابخانه رسانه باشد.

## آزمون‌ها و بسته

آزمون خودکار Chromium در `tests/browser_test.py` و گزارش در `tests/report-v1.3.json`: اسکرول، Flex معکوس، Grid نامساوی/مساوی، ارث‌بری فونت، padding/margin، CSS cascade، تفکیک media، رندر فونت آیکن آفلاین، انتخاب المان، همگام‌سازی ویرایش با JSON و ویرایش repeater.

آزمون Go مسیر انتشار: انتخاب نسخه به ترتیب عددی، GET، HEAD بدون بدنه و 404 برای فایل ناموجود.

EXE برای Windows amd64 کراس‌کامپایل شده است. اجرای EXE در ویندوز و ایمپورت عملی در یک نصب واقعی وردپرس/المنتور در این محیط انجام نشده؛ پس از واردکردن قالب در سایت آزمایشی، نتیجه نهایی بررسی شود.

## فایل‌های انتشار

- `versions/HTML2Elementor-Windows-v1.3.0.zip`: EXE جدید، راهنما، یادداشت انتشار و سورس قابل ویرایش.
- همه ZIPهای تاریخی **موجود** بدون تغییر در versions کپی شده‌اند: نام اولیه بدون شماره، v1.1 و v1.2.1.
- `manifest.json`: اندازه و SHA-256 هر بسته. نسخه تاریخی ناموجود بازسازی یا جعل نشده است.
- آرشیو تجمیعی شامل پوشه versions و همین بسته‌های مستقل است.
