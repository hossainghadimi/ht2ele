# HTML2Elementor 1.8.0 — روند دو مرحله‌ای + چت‌باکس AI + مدل‌های محلی + GPU/CPU همزمان

## تغییرات اصلی

### ۱. روند دو مرحله‌ای با چت‌باکس هوش مصنوعی در هر مرحله

- **مرحلهٔ ۱ — تصویر به HTML** (تب «مرحلهٔ ۱: تصویر به HTML»): تصویر طرح را وارد کنید؛ مدل بینایی ساختار را تشخیص می‌دهد و برنامه **HTML بازسازی‌شده** می‌سازد. حالا:
  - **چت‌باکس AI**: بدون لمس کد، تغییر را بنویسید («دکمه‌ها را آبی کن»، «یک سکشن تماس اضافه کن»). مدل محلی سند کامل به‌روز را برمی‌گرداند؛ **پیش از اعمال، پیش‌نمایش قبل/بعد نمایش داده می‌شود** و بدون دکمهٔ «اعمال تغییر» چیزی عوض نمی‌شود.
  - کادر ویرایش مستقیم HTML + پیش‌نمایش زنده هم کنار چت‌باکس است.
  - **تأیید نهایی**: دکمهٔ «تأیید نهایی و انتقال به مرحلهٔ ۲» HTML تاییدشده را به مرحلهٔ دوم می‌فرستد.
- **مرحلهٔ ۲ — HTML به المنتور** (تب «مرحلهٔ ۲: HTML به المنتور»): HTML تاییدشده در بوم ورودی می‌آید؛ **چت‌باکس همین تب** اصلاحات نهایی را انجام می‌دهد (اعمال، با پشتیبانی Undo در بوم ورودی)، سپس «تبدیل به المنتور» و دانلود JSON + CSS + ZIP.

چت‌باکس‌ها چندگام هستند (تاریخچهٔ کوتاه گفت‌وگو ارسال می‌شود) و با **هر مدل GGUF متنی** کار می‌کنند — نیازی به مدل بینایی فعال ندارند. اگر مدل فعال بینایی باشد، تصویر اصلی به‌عنوان مرجع هم به درخواست چت مرحلهٔ ۱ اضافه می‌شود.

### ۲. مدیریت مدل‌های محلی — ثبت، اسکن، ایمپورت

در «کارگاه AI»:
- **ثبت مسیر** (مانند قبل) با اعتبارسنجی سرآیند GGUF سمت سرور.
- **اسکن دیسک**: دکمهٔ «🔍 اسکن دیسک» پوشه‌های رایج (`D:\Models`، `C:\Models`، `%LOCALAPPDATA%\HTML2Elementor-models`، `models` کنار برنامه) را بررسی می‌کند، فایل‌ها را با **تعداد لایهٔ واقعی مدل (خوانده‌شده از متادیتای GGUF)** و حجم فهرست می‌کند و با یک کلیک ثبت می‌کند؛ mmproj هم‌خانواده را خودکار جفت می‌کند.
- **ایمپورت مستقیم فایل** (تا 8MB): برای مدل‌های کوچک؛ فایل به `HTML2Elementor-data/models` ذخیره و ثبت می‌شود.
- **پیشنهادهای مدل برای سیستم ۸GB VRAM** با لینک مخزن رسمی:
  - بینایی دقت بالا: `Qwen3-VL-8B-Instruct · Q4_K_M + mmproj` (حالت hybrid)
  - بینایی سریع: `Qwen3-VL-4B-Instruct · Q4_K_M + mmproj Q8_0`
  - چت‌باکس‌ها: `Qwen3-4B-Instruct · Q4_K_M` (متنی، بدون mmproj)

### ۳. استفادهٔ هم‌زمان GPU و CPU (حالت hybrid)

- حالت جدید **`hybrid`**: موتور CUDA (`engine-cuda`) با **تعداد لایهٔ محدود GPU (`-ngl`)** اجرا می‌شود؛ لایه‌های offload‌شده روی GPU و ماست روی CPU اجرا می‌شوند — **هر دو پردازنده هم‌زمان کار می‌کنند**.
- مقدار ngl پیش‌فرض **خودکار** است: تعداد لایه از فایل GGUF خوانده می‌شود و از VRAM (پیش‌فرض ۸GB، قابل تنظیم) تخمین زده می‌شود (فرمول: حدود ۷۰٪ VRAM منهای ۱GB برای KV/کنتکست GPU). در «کارگاه AI» می‌توانید ngl را دستی تعیین کنید.
- برای سیستم‌های نمونهٔ این پروژه (i5-12400 + 32GB RAM + RTX 3050 8GB): مدل ۸B با hybrid گزینهٔ دقت بالاتر است؛ مدل ۴B معمولاً همهٔ لایه‌ها را در VRAM جا می‌گذارد و سریع‌تر است.
- حالت `cuda` (تمام GPU) و `cpu` بدون تغییر موجودند.

## اجرا

- بستهٔ ویندوز: EXE + پوشه‌های `runtime`، `ai`، `engine` (CPU). برای حالت hybrid/CUDA، موتور `engine-cuda` (همان انتشار رسمی llama.cpp) در کنار EXE لازم است — دقیقاً مثل نسخهٔ ۱.۷.۰.
- از روی سورس: `run.bat` / `run.sh` + وابستگی‌های `requirements-ai.txt`.

## چه چیزهایی تست شده‌اند

- **E2E سرویس AI با موتور شبیه‌ساز llama.cpp** (پوشهٔ `tests/`): ثبت/اسکن/ایمپورت مدل، شروع موتور hybrid و بررسی آگومان‌های `-ngl/--mmproj/--port`، چت (متن، چندگام، max_tokens)، و مسیر کامل `vision/analyze` با اعتبارسنجی صحنه — `tests/report-v1.8.0.json`.
- تست‌های نسخهٔ ۱.۷.۰ (contract/موتور/رابط) بدون تغییر حفظ شده‌اند.
- اعتبارسنجی syntax تمام JS فرانت و بیلد بصری EXE (Go) در بیلد بعدی.

## چه چیزهایی **تست نشده‌اند** (صادقانه)

- اجرای واقعی Qwen3-VL (4B/8B) روی ویندوز/RTX 3050 — هنوز.
- تطبیق بایت‌به‌بایت DLLهای موتور با انتشار رسمی b11095 در محیط تست (محدودیت شبکه) — با `engine/SHA256SUMS` و هش رسمی `170b23e0...` در `DEPENDENCIES.json` قابل راستی‌آزمایی است.
- ایمپورت زندهٔ وردپرس.
- دقت OCR/چیدمان مدل‌های بزرگ‌تر روی صفحات واقعی (بسته به مدل و وضوح تصویر).

## محدودیت‌ها

- چت‌باکس فقط HTML/CSS سند جاری را می‌بیند؛ تغییرات فرامینی (جاکواواسکریپت) انجام نمی‌دهد و از افزودن اسکریپت/iframe/URL خارجی قهر است.
- هر درخواست چت، سند (تا 80KB) را برای مدل می‌فرستد؛ روی مدل‌های کوچک CPU ممکن است صبر طولانی باشد.
- ngl خودکار تخمین است؛ اگر VRAM ناکافی بود موتور خطا می‌دهد — ngl یا VRAM را کم کنید.
- خروجی متن مدل همیشه نیازمند تأیید دستی است؛ هیچ خروجی‌ای خودکار روی سند اعمال نمی‌شود.
