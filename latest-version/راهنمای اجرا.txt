نسخه ۱.۷.۰ — ویندوز ۱۰ و ۱۱، ۶۴بیتی

ابتدا ZIP را استخراج کنید. اگر نسخه قبلی باز است، پنجره آن را ببندید.
همه پوشه‌های runtime و ai و engine باید کنار EXE بمانند. روی HTML2Elementor.exe دوبار کلیک کنید؛ پایتون و کتابخانه‌ها و موتور CPU داخل بسته‌اند و نصب جداگانه لازم نیست. وزن مدل و CUDA داخل بسته نیستند.
مرورگر باز می‌شود. پنجره کنسول باید باز بماند.
در صورت هشدار ویندوز درباره امضای دیجیتال، ابتدا منبع فایل و هش بسته را بررسی کنید.

HTML و فایل‌های CSS مرتبط را وارد کنید و تبدیل را بزنید.
در پیش‌نمایش اسکرول کنید و روی المان برای ویرایش کلیک کنید.
قالب JSON و CSS همراه آن هر دو باید در سایت استفاده شوند.
فایل RELEASE-v1.7.0.md دامنه شناسایی ویجت‌ها و محدودیت‌ها را توضیح می‌دهد.
سورس قابل‌ویرایش داخل source قرار دارد.
