# latest-version — آخرین نسخه نرم‌افزار برای تحلیل

این پوشه محل قرار دادن **آخرین نسخهٔ HTML2Elementor** برای تحلیل دقیق‌تر است.

## چطور فایل بگذارید؟

1. آخرین نسخه (یا ZIP کامل آن) را داخل همین پوشه بگذارید، مثلاً:
   - `latest-version/HTML2Elementor-v1.8.0/` — نسخه استخراج‌شده، یا
   - `latest-version/HTML2Elementor-v1.8.0.zip` — بستهٔ کامل
2. روی همین شاخه (`arena/01a0cfe3-ht2ele`) commit و push کنید، یا فایل را در چت بفرستید تا من ثبت کنم.

## بهتر است شامل این موارد باشد

- سورس کامل: `web/`, `ai/`, فایل‌های `.go` و `.py`, `docs/`, `tests/`
- `versions/manifest.json` (نام و SHA-256 بسته)
- یادداشت انتشار جدید: `docs/RELEASE-vX.Y.Z.md`
- تغییرات از نسخهٔ قبلی (اختیاری ولی کمک‌کننده)

## بهتر است **نباشد** (برای کوچک ماندن و حفظ حریم خصوصی)

- کش‌ها: `.config/`, `go/pkg/`, `__pycache__/`, `node_modules/`
- وزن مدل‌ها (GGUF) — فقط نام و هش آن‌ها کافی است
- گزارش‌های خام سخت‌افزار حاوی شمارهٔ سریال (مثل `POLARIS-original.txt`)
- خروجی‌های بیلد بزرگ؛ اگر لازم شد فقط SHA-256 کافی است

> نکته: نسخهٔ فعلی مرجع (۱٫۷٫۰) از `workspace-0.zip` ریشهٔ ریپازیتوری استخراج شده و برای مقایسهٔ نسخه‌ها در دسترس است.
